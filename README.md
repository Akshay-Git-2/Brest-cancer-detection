# 🩺 Breast Cancer Detection Using Deep Learning

A Deep Learning-based Breast Cancer Detection system developed using **Python, TensorFlow/Keras, and Scikit-learn**.

The project uses the **Breast Cancer Wisconsin Dataset** and a Neural Network model to classify tumors into:

- ✅ Benign Breast Tumor
- ⚠️ Malignant Breast Cancer

---

## 📌 Project Overview

Breast cancer is one of the most common types of cancer. Early detection can play an important role in improving treatment outcomes.

This project demonstrates how Deep Learning can be used to analyze tumor-related measurements and classify a tumor as **Benign** or **Malignant**.

The model uses **30 numerical features** describing characteristics of cell nuclei obtained from breast mass images.

---

## 🎯 Objectives

- Build a Breast Cancer Detection model using Deep Learning.
- Preprocess and scale medical dataset features.
- Train a Neural Network using TensorFlow/Keras.
- Evaluate the model using multiple performance metrics.
- Visualize model performance using graphs.
- Test the model using new patient feature values.
- Save the trained model for future predictions.
